# Tugas Pemrograman Python

Nama: Putra Maulana  
Mata Kuliah: Pemrograman Python

## Deskripsi Tugas

Berisi dua program Python yang dibuat untuk tugas mata kuliah Pemrograman.

## Daftar Program

1. Rekapitulasi Nilai Mata Kuliah
File: `Soal1.py`

Program ini digunakan untuk mengolah dan merekapitulasi nilai mata kuliah mahasiswa berdasarkan nilai yang diperoleh.

2. Struk Pengiriman Toko Daring
File: `Soal2.py`

Program ini digunakan untuk membuat struk pengiriman pada toko daring yang memuat informasi barang, jumlah pembelian, harga, dan biaya pengiriman.

## Tujuan

Melatih kemampuan dalam menggunakan bahasa pemrograman Python untuk mengolah data, melakukan perhitungan, dan menghasilkan informasi secara terstruktur.
